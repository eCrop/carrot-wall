# docs/specs

One file per feature, written before the code. `/spec` writes here from Day 2 onward.

Name files `<NN>-<feature-name>.md`, matching the number and slug of the corresponding file
in `docs/intents/` (e.g. `docs/intents/02-submit-a-post.md` → `docs/specs/02-submit-a-post.md`).
A plan for that slice is the same name with a `-plan` suffix: `02-submit-a-post-plan.md`.

The app's own spec lives at the repo root (`spec.md`) with its `plan.md`.
